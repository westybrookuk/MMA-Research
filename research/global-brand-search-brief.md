## 2. Registers and search routes

|---|---|---|

Thailand note [FACT]: first-to-file, class-specific; search both the Latin spelling and a Thai-script/phonetic transcription (e.g. LocalFooting → โลคัลฟุตติ้ง). Good classes to consider: **35** (advertising/business info, directory, affiliate commerce), **39** (travel/transport information), **41** (education/guides/content), **42** (SaaS/software/app), **43** (accommodation referral — if the directory includes stays), **45** (legal/visa *information* referral — describe carefully as signposting). Final classes: the professional's call.

## 3. What to look for (per name)
1. **Identical marks** in any relevant class.
2. **Similar marks** (phonetic/visual/conceptual) — e.g. for CityOrienteer: any "orienteer / orienteer + city/travel" marks; for LocalFooting: "footing/foothold/local + city/relocation"; for NewHereCo: "new here / new in city" brands.
3. **Known conflicting uses already identified** to verify:
   - Relocity (relocity.com — B2B relocation SaaS) and Relocify (NL) — relevant if any "reloc-" variant is revisited.
   - Orienteer = a US music-PR firm (orienteer.us) and an outdoor navigation app (Barleycorn; orienteer.co) — assess sector/class overlap for CityOrienteer.
   - "New here" is a common phrase and YouTube @newhereco is taken — assess descriptiveness/third-party use for NewHereCo.
4. **Domain + handle mirror:** confirm registrar availability of the exact `.com` (and `.io/.app/.co/.co.uk`) and the exact handles (YouTube/X/Instagram/TikTok/LinkedIn/Facebook), since a blocked handle or premium domain affects usability.
5. **Meaning/pronunciation check** in Thai (and other launch languages) — confirm no unintended meaning; confirm transliteration.

## 4. Deliverables requested from the reviewer
- Per name: clear / proceed-with-caution / blocked, per register and per class.
- Recommended classes to file, for UK → EU (via EUIPO or Madrid) and Thailand, with Thailand prioritised given Bangkok-first.
- A note on whether the name should be a word mark, word+logo, or composite (especially NewHereCo, which is descriptive).
- Confirmation that using destination editions ("Bangkok Footing", etc.) does not create new conflicts and whether editions need separate filings.

## 5. Standing reminders
- This brief does **not** authorise registration; no domain/account/social should be purchased until the reviewer returns and the operator approves.
- Domain availability shown in the CSV is a DNS screen, not a registry check; availability changes daily.
- Regulated areas (visa/legal/insurance) stay signpost-only regardless of brand; no trademark filing should imply regulated-services classification that AbroadMate/the new entity does not provide.
